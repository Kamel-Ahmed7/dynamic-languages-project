# مختبر الخوارزميات التفاعلي

## 1. نظرة عامة
مشروع لمقرر **Dynamic Languages** مبني بـ HTML5 + CSS3 + Vanilla JavaScript فقط، ويعرض مسألتين، كل مسألة تُحَل بخوارزميتين ثم تُقارَن النتائج:

| المسألة | الخوارزمية 1 | الخوارزمية 2 |
|---|---|---|
| مقارنة النصوص | LCS | Edit Distance |
| أقصر مسار على شبكة | Dijkstra | A* |

**لماذا المقارنة؟** لأن الخوارزميتين تحلان نفس المدخلات بمنطقين مختلفين، فتظهر فروق السلوك والكفاءة عمليًا: LCS يقيس *ما يتشابه*، وEdit Distance يقيس *كم نحتاج لنحوّل*. وDijkstra يبحث بعمى في كل الاتجاهات، بينما A* يستعمل heuristic لتوجيه البحث.

## 2. المسألة الأولى: مقارنة النصوص (Dynamic Programming)
نفترض النصين `A` (طوله m) و`B` (طوله n)، والجدول بحجم (m+1)×(n+1).

### LCS (Longest Common Subsequence)
- **الحالة الأساسية:** `L[i][0] = L[0][j] = 0`
- **العلاقة التكرارية:**
  - إذا `A[i] = B[j]` ⇒ `L[i][j] = L[i-1][j-1] + 1`
  - وإلا ⇒ `L[i][j] = max(L[i-1][j], L[i][j-1])`
- **Backtracking:** من الخلية (m,n): تطابق ⇒ نأخذ الحرف وننتقل قطريًا، وإلا نتحرك نحو الأكبر (أعلى/يسار).
- **التعقيد:** الزمن `O(m×n)`، الذاكرة `O(m×n)` (ويمكن تقليلها إلى `O(min(m,n))` إذا لم نحتج إلى الرجوع).

### Edit Distance (Levenshtein)
- **الحالة الأساسية:** `D[i][0] = i` و`D[0][j] = j`
- **العلاقة التكرارية:**
  - تطابق ⇒ `D[i][j] = D[i-1][j-1]`
  - وإلا ⇒ `D[i][j] = 1 + min(D[i-1][j] (حذف), D[i][j-1] (إضافة), D[i-1][j-1] (استبدال))`
- **Backtracking:** نستخرج تسلسل العمليات: تطابق / استبدال / حذف / إضافة.
- **التعقيد:** الزمن `O(m×n)`، الذاكرة `O(m×n)`.

نسبة التشابه المعروضة = `2×LCS / (m+n)`.

## 3. المسألة الثانية: أقصر مسار على شبكة موزونة
الشبكة 16×9: تكلفة الخلية العادية 1، والتضاريس 5، والجدار غير قابل للعبور، والحركة في 4 اتجاهات.

- **Dijkstra:** يختار دائمًا العقدة ذات أقل `g(n)` (التكلفة الفعلية من البداية). مضمون الأمثلية، لكنه يتوسع في كل الاتجاهات.
- **A\*:** يختار أقل `f(n) = g(n) + h(n)` حيث `h(n)` = مسافة Manhattan إلى الهدف:
  `h(n) = |r - r_goal| + |c - c_goal|`. وهي **admissible** (لا تبالغ في التقدير لأن أقل تكلفة خطوة = 1)، فيبقى A* مثاليًا مع استكشاف عقد أقل.
- **التعقيد:** الزمن `O(E log V)` مع طابور أولويات (النسخة المعروضة تبحث خطيًا في القائمة لتبسيط الكود)، والذاكرة `O(V)`. في A* يعتمد الأداء الفعلي على جودة `h`.

## 4. كيفية التشغيل والعرض في المعمل
1. ضع الملفات الثلاثة (`index.html`, `style.css`, `script.js`) في مجلد واحد وافتح `index.html` في المتصفح (لا يلزم خادم).
2. **المسألة 1:** اختر preset (مثل kitten/sitting) ⇒ اختر LCS أو Edit Distance ⇒ اضغط **تشغيل** وراقب: الخلية الحالية (برتقالي)، الخلايا المعتمد عليها (بنفسجي)، والمعادلة في صندوق الشرح، ثم مسار الرجوع (ذهبي). قارن بطاقتي النتائج أسفل الجدول.
3. **المسألة 2:** اضغط «مثال جاهز» ⇒ **تشغيل**. شاهد Dijkstra يتوسع دائريًا وA* يتجه نحو الهدف. فعّل «إظهار القيم» لعرض g/h/f. ارسم جدرانًا وتضاريس بالسحب، وحرّك S وG عبر الأدوات، أو استخدم «متاهة عشوائية».
4. في لوحة المقارنة: حالة المسار، التكلفة، عدد الخطوات، العقد المستكشَفة، ونسبة كفاءة A*.
5. التحكم: تشغيل / إيقاف / خطوة / إعادة / شريط السرعة.
